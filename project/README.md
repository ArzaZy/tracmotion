# TracMotion

Mobile-first dark motion-graphics editor foundation.

## Requirements
- Node.js 20.9+ for the Next.js starter. AM Runtime integration separately documents Node.js 24+.
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Checks
```bash
npm run lint
npm run build
```

## Important
This is a starter foundation, not a completed editor. The preview, timeline, preset import, and render functions are clearly marked as placeholders until implemented and tested. AM Runtime is not bundled; follow `../docs/AM_RUNTIME_RESEARCH.md`.

## GitHub Codespaces
Upload/extract the `project` folder contents into your repository root, or upload the ZIP contents through GitHub. Then open Codespaces and run the commands above.
