# TracMotion Complete Pack

Contains:
- `project/`: starter Next.js project source (not yet installed or build-tested).
- `prompts/`: eight sequential Claude prompts.
- `docs/`: AM Runtime research summary and architecture.
- `scripts/`: placeholder for future helper scripts.

## Start
1. Create a GitHub repository named `tracmotion`.
2. Upload the contents of `project/` into the repository root.
3. Open GitHub Codespaces.
4. Run `npm install`, then `npm run dev`.
5. Open the preview port 3000.
6. Use prompts one at a time, in numeric order. Do not send all prompts in one message.

## Important status
This ZIP is a starter project and research bundle. The AM Runtime package is not included. Its documented installation has not been tested in this environment. The app UI has placeholder editor/import/export areas. Do not treat the mock adapter as a real renderer.
